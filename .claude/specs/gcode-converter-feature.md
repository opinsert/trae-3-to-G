# G代码转换器功能增强

## 目标

增强自然语言转换体验：生成前显示已输入和缺失参数，生成后分别展示 G 代码和工序信息，并提供 G 代码验证入口。

## 范围

- 自然语言输入时显示参数完整性。
- G 代码和工序信息使用独立弹窗。
- 支持复制 G 代码和打开验证工具。
- 后端提供参数预检查接口。
- 不修改参数类型和 G 代码生成算法。

## 实现与验收

- [x] `NaturalLanguageInput` 实时显示已输入参数。
- [x] `NaturalLanguageInput` 实时显示缺失参数。
- [x] G 代码在独立弹窗显示。
- [x] 工序信息在独立弹窗显示。
- [x] 两个弹窗可独立关闭。
- [x] G 代码弹窗可打开验证页面。
- [x] 复制 G 代码功能可用。
- [x] 后端预检查接口返回参数状态。

## 约束

- 参数检查响应应小于 1 秒。
- 前端使用 Vue 3、Vite 和 Tailwind CSS。
- 外部验证工具须使用用户确认或项目已有的地址。
