# 工序图转换 UI 重构 V2

## 目标

根据标准工业工序卡图片，将工序图转换页面重构为与真实表格一致的两栏布局，同时保持 OCR 和 G 代码生成功能可用。

## 范围

- 左栏保留图片上传。
- 右栏采用工序卡表格布局。
- 后端 `ProcessCard` 和 `DrawingStep` 支持完整字段。
- OCR 提取并填充新增字段。
- 不修改自然语言和 STL 选项卡，不改变 G 代码生成算法。

## 字段与布局

基本信息采用 4 行 4 列：

1. 车间、工序号、工序名称、材料牌号。
2. 毛坯种类、毛坯外形尺寸、毛坯还可制件数、每台件数。
3. 设备名称、设备型号、设备编号、同时加工件数。
4. 夹具编号、夹具名称、切削液。

工位器具与工时区域包括：工位器具编号、工位器具名称、准终工时、单件工时。

工步表格包括：工步号、工步内容、工艺装备、主轴转速、切削速度、进给量、被吃刀量、进给次数、机动工时、辅助工时。
