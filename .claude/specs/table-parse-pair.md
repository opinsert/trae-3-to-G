# 视觉 GPT 表格结构化识别

## 目标

通过支持图片输入的视觉 GPT 将机械加工工序卡直接解析为结构化字段，保持 API 和前端表单数据结构不变。

## 规则

- 只接受合法 JSON 结构化结果。
- 字段名必须与 `ProcessCard`、`DrawingStep` 和前端表单一致。
- `drawing_steps` 按工步表逐行提取，数字字段去除单位。
- 不猜测图片中不存在的信息。
- 未配置模型、请求失败或未识别到有效字段时明确报错。

## 验收

- [ ] 两张参考工序卡图片均能提取基本字段。
- [ ] 工步表内容、刀具和切削参数正确映射到 `drawing_steps`。
- [ ] 缺少 API key、请求异常和空结果不会返回假成功。
- [ ] 前端可显示并允许用户修正识别结果。

## 约束

- `VISION_OCR_MODEL` 必须支持 `image_url` 视觉输入。
- API key 由用户环境配置，不写入安装包或版本库。
- 不引入其他云端或本地 OCR 引擎。
