# CNC 代码生成安全规则

本文档定义 CNC G 代码生成器与验证器的安全约束，适用于本项目的所有 G 代码生成与验证逻辑。

## 坐标系统

**工件坐标系（G54）- 绝对坐标（G90）**

- X 轴范围：0.0 ~ 200.0 mm
- Y 轴范围：0.0 ~ 200.0 mm  
- Z 轴范围：-100.0 ~ 100.0 mm（Z=0 为工件表面，负值为切入工件，正值为工件上方）
- 超出范围触发验证器错误码：E003

**重要说明**：

- 项目采用**绝对坐标系统（G90）**，所有坐标值均为距离工件原点的绝对位置
- Z=0 是工件顶面，Z 负值表示刀具切入工件内部（切削区域），Z 正值表示刀具在工件上方（安全区域）
- **允许负 Z 坐标**用于表示切削深度（例如切深 5mm 表示为 Z=-5.0）
- 生成器可直接输出负 Z 坐标到 G 代码
- 验证器检查最终生成的坐标是否在机床范围内（-100..100）

## 进给与速度限制

**切削进给速度（G94 模式，单位 mm/min）**

- 最大切削进给：5000 mm/min
- 推荐粗加工进给：200-500 mm/min
- 推荐精加工进给：100-200 mm/min
- 推荐快速定位进给：500-1000 mm/min
- 超速触发验证器错误码：E009

**主轴转速（S 指令，单位 rpm）**

- 最大主轴转速：12000 rpm
- 推荐铝合金加工：3000-8000 rpm
- 推荐钢材加工：2000-5000 rpm
- 超速触发验证器错误码：E010

## 必需的安全指令

### 程序初始化（必需）

```gcode
G90 G54 G21 G94  ; 绝对坐标、工件坐标系、毫米单位、每分钟进给
G17 G40 G49 G80  ; XY平面、取消刀补、取消长度补偿、取消固定循环
```

- 缺少 G21（毫米单位）或 G94（进给模式）触发 E006
- 缺少 G90（绝对坐标）触发 E008

### 切削前检查（必需）

```gcode
M03 S3000  ; 启动主轴（顺时针）
M08        ; 启动冷却液
```

- 切削前未启动主轴触发 E004
- 切削前未启动冷却液触发 E005

### 安全高度要求

- 快速移动（G00）前必须提升到安全 Z 高度（≥ 5.0mm）
- 推荐回退高度：50.0mm（项目默认 `retract_z`）
- 违反触发 E007

### 程序结束（必需）

```gcode
G00 Z50.0 M09  ; 提升到安全高度，关闭冷却液
M05            ; 停止主轴
M30            ; 程序结束并复位
```

## 工序特定规则

### 钻孔循环（深孔加工）

- 深度超过刀具直径 3 倍时必须使用分层钻削（peck drilling）
- 推荐单次进给深度：刀具直径 × 1.5
- 每次回退到孔口排屑后再继续

### 型腔铣削

- 必须使用斜坡进刀或螺旋下刀，禁止垂直下刀
- 单层切深不超过刀具直径的 50%
- 精加工留量：侧面 0.2-0.5mm，底面 0.1-0.2mm

### 轮廓加工

- 粗加工留量：0.5-1.0mm
- 精加工分粗精至少两次走刀
- 拐角处自动减速（进给覆盖 F 值）

## 验证器错误码

| 代码 | 含义 | 触发条件 |
|------|------|----------|
| E001 | 缺少程序结束指令 | 未找到 M02/M30 |
| E002 | 未初始化坐标系 | 切削前未使用 G54-G59 |
| E003 | 坐标超出范围 | X/Y/Z 超出机床限制 |
| E004 | 主轴未启动 | 切削前未找到 M03/M04 |
| E005 | 冷却液未启动 | 切削前未找到 M08 |
| E006 | 缺少单位或进给模式 | 未找到 G21 或 G94 |
| E007 | 快速移动不安全 | G00 时 Z < safe_z |
| E008 | 未设置绝对坐标 | 未找到 G90 |
| E009 | 进给速度超限 | F 值 > max_cutting_feed |
| E010 | 主轴转速超限 | S 值 > max_spindle_rpm |
| W001 | 零步距移动 | 连续相同坐标指令 |
| W002 | 快速切削可能 | G00 + 低 Z 坐标 |

## 代码审查要点

修改 G 代码生成器或验证器时必须确认：

1. 新生成的 G 代码通过 `test_gcode_validator.py` 所有测试
2. 坐标值在 `MachineProfile` 定义的范围内（X/Y 0..200，Z -100..100）
3. 切削指令前已启动主轴与冷却液
4. 快速移动前已提升到安全高度
5. 程序以 M30 结束并关闭主轴/冷却液
6. Z 坐标在允许范围内（-100..100），负值用于切削，正值用于安全移动
